# Подключение Guardian Eye к Home Assistant

[English](INSTALL.md)

## Сначала: брокер и MQTT в Home Assistant

Компонент не устанавливает MQTT-брокер и не добавляет интеграцию MQTT в HA. Сделайте это первым:

1. **Брокер.** Если его нет, установите. В Home Assistant OS проще всего поставить
   **Mosquitto broker** из магазина (**Настройки → Приложения**, в старых версиях «Дополнения»).
   У HA в Docker этого раздела нет: поставьте отдельный Mosquitto, например рядом в Docker.
2. **Интеграция MQTT в HA.** **Настройки → Устройства и службы → Добавить интеграцию → MQTT**.
   Укажите брокер так, как он доступен с сервера HA: дополнение Mosquitto обычно находится само,
   брокер в той же Docker-сети — по имени контейнера (например, `mqtt`), брокер на другом
   устройстве — по его IP-адресу. Добавьте порт и учётные данные, если нужны.
3. Убедитесь, что интеграция **MQTT** работает без ошибки подключения.

## Установить один раз

1. В GE откройте **Настройки → Умный дом → Home Assistant** и скачайте предлагаемый комплект.
2. Из `guardian-eye-ha-setup.zip` скопируйте папку `custom_components/guardian_eye` в каталог
   конфигурации HA (обычно `/config/custom_components/guardian_eye`). При обновлении замените
   эту папку целиком. Остальную конфигурацию HA сохраняйте.
3. Перезапустите Home Assistant.

Панель уже находится внутри компонента. Отдельные файлы в `www`, ресурсы JavaScript и YAML
добавлять не требуется.

## Подключить через код

В GE укажите сервер MQTT, порт и учётные данные в обычных полях и проверьте соединение.
GE и HA должны использовать один брокер. Автонастройка расположена под блоком MQTT.

1. В GE нажмите **Подключить Home Assistant** и скопируйте код. Оставьте это окно открытым.
2. В HA откройте **Настройки → Устройства и службы → Добавить интеграцию → Guardian Eye**,
   выберите подключение по коду, вставьте код и завершите добавление.

Код действует пять минут. Если GE предлагает несколько сетевых адресов, выберите адрес сети,
доступной серверу HA. Устройства и датчики появятся автоматически; панель **Guardian Eye** —
в боковом меню HA. Если меню уже было открыто, обновите страницу.

GE проверит уже введённые настройки MQTT, включит доступ к видео и создаст отдельный ключ
для просмотра. Настройки сервера, пароля, TLS и префикса Discovery сохраняются. Постоянный ключ
видео остаётся на сервере HA; доступ к камерам проверяется по правам пользователя HA.
Язык берётся из HA, отдельного выбора языка нет.

## Использовать

Включите **Захват** камеры и нажмите кнопку просмотра. **Остановить просмотр** закрывает видео
в этом браузере; захват и запись продолжаются. Датчики человека, транспорта и животных работают
при включённой AI-детекции, а движение — отдельный датчик. Назначайте действия через обычный
редактор автоматизаций HA. Примеры автоматизаций автоматически не устанавливаются.

## Обновить или подключить повторно

GE предлагает комплект, подходящий установленной сборке. Скачайте его, замените только папку
`custom_components/guardian_eye`, перезапустите HA и обновите браузер. Панель обновится вместе
с компонентом. Существующая раскладка, идентификаторы и автоматизации сохраняются.

Чтобы заменить доступ к GE, создайте новый код и откройте **Перенастроить** у существующей
интеграции Guardian Eye. Удалять интеграцию не нужно. При переходе с ручной настройки выполните
это один раз: GE и HA согласуют защищённый доступ, а ресурс прежней панели обновится автоматически.

Для разных версий GE могут требоваться разные комплекты. Используйте комплект, предложенный GE;
если подходящего выпуска нет, оставьте установленную версию. Версии записаны в
`guardian-eye-package.json`, включённом в архив. Старые выпуски и их ссылки сохраняются.

## Если подключение не удалось

- **MQTT не настроен:** добавьте интеграцию MQTT в HA. Установка компонента Guardian Eye не устанавливает брокер.
- **Брокер недоступен:** проверьте, что его порт доступен с компьютера GE. Для Mosquitto в HA OS
  порт брокера должен быть доступен через адрес сервера HA.
- **Код недействителен или истёк:** создайте новый код в GE. Проверьте часы на обоих устройствах.
- **Несовместимая версия:** установите комплект, предложенный вашей версией GE.
- **Видео отсутствует:** проверьте захват камеры и сетевую доступность компьютера GE.

Настройка рассчитана на GE и сервер HA в доступной друг другу сети. HA подключается к временно
открытому HTTPS-порту из кода, затем к API GE (по умолчанию TCP 8890). Браузер обменивается
сигнализацией через HA, а видео WebRTC поступает непосредственно с GE (по умолчанию UDP 8189).
Для просмотра из другой сети нужен маршрут к GE, например VPN. Сам комплект NAT и VPN не настраивает.

Параметры TLS и CA используются из существующей конфигурации MQTT в GE.
Ручные настройки остаются открытыми. В HA также доступен ручной ввод адреса GE и ключа доступа.

HACS-репозиторий Guardian.Eye.Dashboard относится к категории Dashboard и устанавливает только
панель. Для подключения через код используйте полный комплект из GE; отдельно устанавливать
панель через HACS для этого не требуется.
