# Подключение Guardian Eye к Home Assistant

[English](INSTALL.md)

Используйте **совместимый комплект, который предлагает установленная версия GE** в настройках
Home Assistant. Он содержит согласованные версии панели и компонента HA. Не заменяйте панель
самой новой из другого выпуска. Точные версии и границы совместимости записаны в
`guardian-eye-package.json` внутри архива.

## 1. Подключить MQTT

Установите MQTT-брокер и подключите к нему интеграцию MQTT в Home Assistant. В GE включите
Home Assistant, укажите тот же брокер, проверьте подключение, включите Discovery и сохраните
настройки. Камеры, датчики и команды появятся автоматически. Интеграция MQTT в HA сама брокер
не устанавливает.

## 2. Установить комплект

1. В GE нажмите **Скачать комплект** — это архив `guardian-eye-ha-setup.zip`.
2. Распакуйте его в **каталог конфигурации Home Assistant**. Для HA OS это `/config`, для Container —
   папка на хосте, подключённая к `/config`. Объедините каталоги из архива с существующими:
   - `custom_components/guardian_eye/`
   - `www/community/guardian-eye-dashboard/`
3. Перезапустите **Home Assistant**, чтобы загрузить Python-компонент.

В архиве нет `configuration.yaml`, паролей или `.storage`. Настройки HA он не заменяет.
Для раздельного развёртывания в том же выпуске есть `guardian-eye-dashboard.zip` и
`guardian-eye-integration.zip`.

## 3. Включить защищённый доступ к видео в GE

MQTT передаёт датчики и команды. Для живого видео дополнительно нужны видеомаршрутизатор и API
доступа GE. По умолчанию API выключен. Добавьте раздел `LiveStreaming` из
[примера конфигурации](INSTALL.md#3-enable-authenticated-video-in-ge) в существующую конфигурацию
GE, сохранив остальные настройки и заменив адреса примера:

- `PublicBaseUrl` — адрес GE, например `http://192.168.1.10:8890`;
- `AllowedNetworks` — разрешённый адрес сервера HA; при Docker это может быть адрес хоста;
- `AllowedViewerOrigins` — точный адрес, по которому открывается HA в браузере;
- `AdvertisedViewerHosts` — адрес GE, доступный браузеру.

Должны быть доступны GE TCP 8890 из HA и GE TCP 8889 / UDP 8189 из браузера. `localhost` и
`0.0.0.0` не подходят для публичного адреса другого устройства. После изменения слушателей
перезапустите GE. Пример HTTP предназначен для доверенной локальной сети.

Если HA работает через HTTPS, для GE тоже настройте HTTPS: HTTPS-адрес `PublicBaseUrl` и
`Security.Tls.Enabled`, `CertificatePath`, `PrivateKeyPath`. Сертификату должны доверять HA и
браузер. Прокси, NAT и доступ извне требуют отдельной настройки сети; архив их не настраивает.

В существующих настройках ключей доступа GE создайте отдельный ключ для HA. Достаточно права
`guardian.media.read`; ключ с полным доступом, который выдаёт текущий диалог GE, также работает.
В HA откройте **Настройки → Устройства и службы → Добавить интеграцию → Guardian Eye**.
Введите адрес API GE и ключ без префикса `Bearer `. Постоянный ключ хранится в HA; браузер получает
временный доступ к камере после проверки прав пользователя HA.

## 4. Добавить панель

1. В HA откройте **Настройки → Панели → Ресурсы**. При необходимости включите расширенный режим
   в профиле HA.
2. Добавьте **JavaScript-модуль** по URL, который показывает GE. Ссылка закреплена за совместимым
   выпуском. Для полностью локальной установки используйте
   `/local/community/guardian-eye-dashboard/Guardian.Eye.Dashboard.js?v=VERSION`, заменив `VERSION`
   версией панели из GE. Выберите один способ; второй ресурс для той же панели не создавайте.
3. Обновите страницу браузера и откройте **Настройки → Панели → Добавить панель → Guardian Eye**.
4. Камеры появятся автоматически из MQTT. Вручную вводить entity ID или YAML не требуется.

Включите **Захват** камеры и нажмите просмотр. Остановка просмотра закрывает видео в этом
браузере, сохраняя захват и запись. Датчики человека, транспорта и животных требуют режима AI;
движение имеет отдельный датчик. Действия назначаются в обычном редакторе автоматизаций HA.
Пример автоматизации со светом не устанавливается. Используется выбранный язык HA.

## Обновление и разные версии GE

После обновления GE снова проверьте совместимый комплект. Установите **обе части одного комплекта**,
перезапустите HA при обновлении Python-компонента, замените URL существующего ресурса панели и
обновите браузер. Существующие интеграцию, панель, идентификаторы камер и автоматизации сохраняйте.
Если совместимого выпуска нет, оставьте установленную версию и проверьте примечания к выпуску.

Выбор учитывает нижнюю включительную и верхнюю исключительную границы версий GE, а также версию
контракта HA в сборке. Для предварительных и локальных сборок нужно отдельное разрешение в каталоге.
Для неизвестного контракта или неподдерживаемой версии GE самая новая панель автоматически не выдаётся.
Ссылки `/vVERSION/` сохраняются. Старый адрес `/latest/` закреплён на 1.0.10 для старых GE,
которые ещё не умеют выбирать совместимые пакеты. Новые GE используют `releases.json`.

Через HACS можно установить панель из публичного репозитория Guardian.Eye.Dashboard, категория
Dashboard. Выбирайте версию, рекомендованную GE: HACS не проверяет версию GE и не устанавливает
Python-компонент из репозитория панели. Компонент берите из того же комплекта.

## Проверка

Сверьте версии в GE, записи интеграции Guardian Eye в HA и файле `guardian-eye-package.json`.
Проверьте MQTT, видео одной камеры, остановку/повторный просмотр и команду управления камерой.
Если видео отсутствует, сначала проверьте захват, адрес API, доступность видеопортов и ключ GE.
